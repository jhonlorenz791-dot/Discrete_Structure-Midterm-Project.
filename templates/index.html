✅ Proof of Validity & Consistency

1
Set Theory: authorized_users ⊆ all_users, restricted_users ∩ authorized_users = ∅, and all users are partitioned into students ∪ faculty ∪ staff ∪ visitors.
2
Logic: If user is restricted, predicate logic always returns False. Boolean function has ¬D term, so if D=True, F=False. Restricted users never get access.
3
Relations: access_permissions maps each user to a set of rooms. The matrix accurately represents this relation. All permissions are explicitly defined.
4
Number Theory: Access level = GCD(permission_bits, 31). 31 is prime, ensuring unique level values. Levels range from 0-31, providing 32 access tiers.
